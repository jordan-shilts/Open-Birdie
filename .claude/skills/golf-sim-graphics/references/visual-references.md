# Visual references for the featured courses

Where to find real footage and benchmark-game frames for each course in `courses/featured.json`, plus product-wide galleries. Use these for the three-way comparison in SKILL.md section 3: your frame, a benchmark frame from the same camera type, and a real photo or flyover.

## 1. Ground rules

- **Everything here is free to view.** Never buy a course bundle, game or subscription to get reference frames. FSX Play's Whistling Straits bundle, for example, is a paid add-on; its product page screenshots are enough.
- **Links only, never files in the repo.** Game screenshots and broadcast footage are copyrighted. Keep saved frames out of git (use a gitignored folder or the chat), and never use them as textures.
- **Real footage is ground truth; game frames are the quality bar.** When the two disagree about the course itself (bunker shapes, trees, colours), follow the real footage.
- **Match the condition.** Compare like with like: same camera band, similar time of day and season.

## 4. Product galleries

What each product is the reference for:

- **EA Sports PGA Tour (Frostbite):** the realism bar for capture, haze and grass. [Courses overview](https://www.ea.com/news/ea-sports-pga-tour-courses-overview).
- **PGA Tour 2K25:** crisp resolution, sunset presets, course-designer surfaces. [Behind-the-scenes and gameplay photos](https://golfwrx.com/753984/pga-tour-2k25-video-game-launch-30-behind-the-scenes-photos-including-gameplay/).
- **TrackMan Virtual Golf 3:** broadcast-clean look and the overlay layer (green grid, contours, tracers, data panels). [Launch post](https://www.trackman.com/blog/golf/virtual-golf-3-and-tps-10), [support article](https://support.trackmangolf.com/hc/en-us/articles/29476947436059-VG-Virtual-Golf-3).
- **Foresight FSX Play:** time of day, night play, rain and fog. [Support page](https://support.foresightsports.com/support/software/fsx-play).
- **GSPro:** the community-course standard and the closest stack to Open-Birdie's (lidar plus imagery). [GSPro](https://gsprogolf.com), [OPCD course creation](https://zerosandonesgcd.com/opcd-course-creation/).
- **TruGolf E6 APEX:** current commercial sim. [Product page](https://trugolf.com/pages/e6-apex).
- **Golf+ (VR):** how a good look survives weak hardware; reference for the Low preset and the sim PC's integrated GPU. [Graphics upgrade write-up](https://www.uploadvr.com/golf-plus-cliffs-course-graphics-upgrade/).

## 5. Getting images in front of the agent

The agent sees an image only when it is in the session: a file the user attaches in chat, a file in the working tree, or an image returned by a tool. It cannot watch YouTube or see images inside a fetched web page.

- **Best:** the user saves a few frames per camera band (address, approach, green, flyover) and attaches them in the agent's chat.
- **Free paintover targets:** use the Hugging Face connector described in SKILL.md section 12; its image tools return images straight into the session.
